# TimeCost

Калькулятор, который пересчитывает стоимость покупки в часы и дни вашей работы.

## Запуск (Android)

```bash
npm install
npx expo start --android
```

Или отсканируйте QR-код в [Expo Go](https://expo.dev/go).

## Возможности

- Ввод часовой ставки и длины рабочего дня
- Пересчёт цены покупки в часы / дни / недели / месяцы работы
- Сохранение ставки на устройстве
- Лёгкий современный интерфейс
- Автоязык устройства из 20 популярных языков (иначе английский)
