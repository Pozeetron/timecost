# Google Play content pack

Ready-to-upload assets for TimeCost.

```
gp_content/
├── LISTING.md                      # titles, descriptions, checklist
├── icon-512.png                    # Play Store icon (512×512, ~148 KB)
├── feature-graphic-1024x500.png    # Feature graphic
├── screenshots/                    # Raw phone screenshots (1080×1920)
├── promo/                          # Screenshots with marketing captions
└── privacy/index.html              # English privacy policy page
```

Host `privacy/index.html` on HTTPS and paste that URL into Google Play Console → App content → Privacy policy.

App icons in `/assets` were also updated for the Expo build.
